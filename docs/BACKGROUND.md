## 방향성 변천사

### 1단계 — 초기 아이디어 (커뮤니티 앱)

최초에는 기독교인들을 위한 **신앙 커뮤니티 앱**으로 시작.

벤치마킹 앱:
- **초원:** 개인 영성 관리 (QT, 질문, 성경, 내 노트, 공동체)
- **요즘처치:** 익명 커뮤니티

초기 방향: "초원(개인 영성)과 요즘처치(커뮤니티) 사이 어딘가"

핵심 메시지: *신앙생활 혼자하면 힘들지만, 함께 뛰면 완주할 수 있다*

초기 구상 기능들:
- 함께 묵상하기 (성경 일독 동아리)
- 커뮤니티 (기독교 질문/고민/이슈)
- 중보기도 (소속 기반 기도 제목 나눔)
- 위젯 (썸원 앱처럼)
- 친구 기록 열람 (to do mate처럼)
- 신앙 유형 테스트 (MBTI처럼)
- 크리스천 크리에이터 콘텐츠
- 교회별 CRM (목사님 어드민, 공지사항)

### 2단계 — 방향성 구체화 (3/3 미팅)

서비스 정의 재수립:

> **"일상에서 재미있는 크리스천 콘텐츠를 소비하고 싶은 1020을 위한 콘텐츠 플랫폼"**

커뮤니티 중심에서 **콘텐츠 소비 중심**으로 피벗.

선택된 3개 핵심 기능:
1. 영상 콘텐츠 — 크리스천 크리에이터 릴스/숏츠 피드
2. 테스트 — 성경 인물 기반 심리테스트 (MBTI 스타일)
3. 미니게임 — 성경 테마 게임들

이 시점에서 앱 이름 후보들 논의 → **GOD MODE (갓모드)** 최종 결정

### 3단계 — 우선순위 확정 (현재)

핵심 목표 지표 2개로 단순화:
1. **사용자 수**
2. **체류 시간**

→ 이 두 지표를 올릴 수 없는 기능은 우선순위 낮춤

MVP 순서: **미니게임 먼저** → 릴스 피드 → 테스트

## 보류된 기능들 (추후 재검토)

커뮤니티 기능들은 방향성은 공감하나 MVP 범위에서 제외:

| 기능 | 보류 이유 |
|------|----------|
| 함께 묵상하기 (챌린지) | MVP 범위 초과, 추후 Phase 4 검토 |
| 중보기도 공간 | 소속 기반 구조 설계 필요, 복잡도 높음 |
| 교회별 CRM / 목사님 어드민 | B2B 성격, 별도 프로덕트로 분리 가능 |
| 셀 기반 방 (단톡방 컨셉) | 연결 범위 정의 선행 필요 |
| 친구 기록 열람 | 소셜 레이어 완성 후 추가 |
| 위젯 | 앱 안정화 후 추가 |
