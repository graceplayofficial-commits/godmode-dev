# Plan: Christian App (기독교 앱)

> **Phase**: Plan
> **Created**: 2026-03-23
> **Status**: Draft

---

## 1. 개요 (Overview)

### 앱 이름 (가칭)
**GODMode** (또는 추후 확정)

### 한 줄 설명
기독교인을 위한 올인원 앱 — 말씀 릴스, 신앙 성격테스트, 미니게임을 한 곳에서.

### 배경 & 문제 정의
- 기독교 관련 영상 콘텐츠가 유튜브 곳곳에 흩어져 있어 찾기 번거로움
- 자신의 신앙 성향/성격을 재미있게 알아볼 수 있는 콘텐츠가 부족함
- 신앙을 게임처럼 즐기며 배울 수 있는 가벼운 앱이 없음

|------|------|

| 사용자 목표 | 매일 기독교 릴스 감상 → 성격테스트로 자기 탐색 → 미니게임으로 말씀 복습 |
| 비즈니스 목표 | 기독교 커뮤니티 내 바이럴, 교회 소그룹/청년부 중심 확산 |

## 4. 핵심 기능 (Core Features)

### Page 1 — 기독교 릴스 피드

> YouTube Data API v3를 활용해 기독교 관련 쇼츠/릴스를 큐레이션

| 항목 | 내용 |
|------|------|
| 데이터 소스 | YouTube Data API v3 |
| 검색 키워드 | "기독교 쇼츠", "예배 릴스", "말씀 shorts", "worship reels" 등 |
| 표시 방식 | 세로 스크롤 숏폼 피드 (TikTok/인스타 릴스 스타일) |
| 필터 | 카테고리별 필터 (찬양, 말씀, 간증, 기도) |
| 저장 기능 | 즐겨찾기 / 나중에 보기 |
| 공유 기능 | 링크 공유, 카카오톡 공유 |

**기술 요구사항**
- YouTube Data API v3 (검색 + 영상 정보)
- API Key 관리 (환경변수)
- 영상 재생: YouTube IFrame Player 또는 youtube_player_flutter

### Page 2 — 기독교 MBTI 성격테스트

> 신앙 스타일/성격을 알아보는 재미있는 테스트

| 항목 | 내용 |
|------|------|
| 테스트 유형 | 기독교 신앙 스타일 MBTI (예: 말씀형 vs 찬양형, 기도형 vs 섬김형) |
| 문항 수 | 12~20문항 (간결하게) |
| 결과 유형 | 8~16가지 신앙 유형 (예: "다윗형", "바울형", "마리아형" 등) |
| 결과 공유 | 결과 카드 이미지 생성 → SNS 공유 |
| 저장 | 내 결과 저장 및 히스토리 보기 |
| 추가 기능 | 친구와 궁합 보기 (두 유형 비교) |

**테스트 예시 문항**
- "예배 중 가장 은혜받는 순간은?" → 찬양할 때 / 말씀 들을 때 / 기도할 때 / 교제할 때
- "신앙생활에서 가장 중요한 것은?" → 큐티 / 봉사 / 기도 / 전도

**결과 유형 예시**

| 유형 | 설명 |
|------|------|
| 다윗형 | 찬양과 예배로 하나님을 만나는 타입 |
| 바울형 | 말씀과 신학적 사고를 중시하는 타입 |
| 에스더형 | 조용하지만 결정적 순간에 믿음으로 행동하는 타입 |
| 베드로형 | 열정적이고 즉흥적, 실수해도 다시 일어서는 타입 |
| 마리아형 | 묵상과 경청을 통해 말씀을 깊이 새기는 타입 |
| 느헤미야형 | 공동체와 조직을 세우는 리더십형 |
| 룻형 | 헌신과 충성으로 관계를 지키는 타입 |
| 요나형 | 갈등하지만 결국 순종하는 현실적인 신앙인 타입 |

### Page 3 — 미니게임 허브

> **토스처럼 앱 안에 앱** — 기독교 테마 미니게임들을 하나의 허브에서 선택해 플레이

각 미니게임은 독립된 앱처럼 동작하며, 게임 허브 화면에서 아이콘을 탭해 진입한다.

---

#### 게임 1 — 노아의 방주 테트리스

| 항목 | 내용 |
|------|------|
| 장르 | 퍼즐 (테트리스 변형) |
| 컨셉 | 창세기 6-8장, 노아의 방주에 동물을 효율적으로 쌓는 게임 |
| 블록 | 동물 2마리씩 쌍으로 구성된 블록 (사자, 코끼리, 토끼 등) |
| 목표 | 방주 공간을 최대한 효율적으로 채워 홍수 전에 방주 완성 |
| 특징 | 쌍을 이루지 못한 동물 블록은 점수 감점, 레벨업 시 동물 종류 추가 |
| 기술 | Flutter + flame 게임 엔진 |

---

#### 게임 2 — 예수님과 오목 (야곱의 씨름)

| 항목 | 내용 |
|------|------|
| 장르 | 보드게임 (오목) |
| 컨셉 | 야곱이 천사와 씨름하듯, 예수님(AI)과 오목 대결 |
| 난이도 | 3단계 (제자, 사도, 선지자) |
| 특징 | 이길 때마다 성경 구절 + 짧은 말씀 카드 보상 |
| AI | Minimax 알고리즘 기반 오목 AI |
| 기술 | Flutter + 커스텀 게임 로직 |

---

#### 게임 3 — 말씀 암송 리듬 게임

| 항목 | 내용 |
|------|------|
| 장르 | 리듬 게임 |
| 컨셉 | 찬양 BGM 비트에 맞춰 떨어지는 말씀 단어를 타이밍에 맞게 클릭 |
| 진행 | 성경 구절이 단어 단위로 분리되어 리듬에 맞춰 낙하 |
| 목표 | 정확한 타이밍에 탭 → 구절 완성 → 말씀 암송 달성 |
| 콘텐츠 | 인기 성경 구절 100선 (요 3:16, 빌 4:13 등) + 찬양 BGM |
| 보상 | 암송 완료 구절은 "암송 성경" 컬렉션에 저장 |
| 기술 | Flutter + flame + 오디오 동기화 |

---

#### 게임 4 — 믿음의 왕국 키우기 (클리커)

| 항목 | 내용 |
|------|------|
| 장르 | 방치형 클리커 (Idle Clicker) |
| 컨셉 | 클릭으로 교회/성전을 짓고 성경 속 도시를 키우는 게임 |
| 진행 | 탭 → 믿음 포인트 적립 → 건물 건설 (성막 → 성전 → 새 예루살렘) |
| 업그레이드 | 기도, 전도, 찬양, 봉사 등 덕목별 업그레이드 |
| 방치 수익 | 앱 꺼져 있어도 시간당 포인트 적립 |
| 특징 | 특정 마일스톤 달성 시 성경 구절/스토리 잠금해제 |
| 기술 | Flutter + SharedPreferences (오프라인 저장) |

---

#### 게임 5 — 성경 인물 카드 수집 (가챠)

| 항목 | 내용 |
|------|------|
| 장르 | 카드 수집 + 가챠 |
| 컨셉 | 성경 인물 카드를 수집하고 능력치를 키우는 컬렉션 게임 |
| 가챠 | 일일 무료 1회 + 게임 내 재화로 추가 뽑기 |
| 카드 등급 | 일반(회색) / 희귀(파랑) / 영웅(보라) / 전설(금색) |
| 능력치 | 믿음, 지혜, 용기, 사랑, 인내 (성경 인물별 고유 스탯) |
| 카드 예시 | 전설: 모세, 다윗, 바울 / 영웅: 기드온, 에스더, 룻 |
| 정보 연동 | 카드 탭 시 해당 인물의 성경 스토리 + 주요 구절 표시 |
| 기술 | Flutter + Firebase (카드 DB, 뽑기 확률 서버 관리) |

---

**게임 허브 공통 요소**

| 요소 | 설명 |
|------|------|
| 허브 UI | 토스 스타일 게임 아이콘 그리드, 신규/업데이트 뱃지 |
| 통합 포인트 | 모든 게임에서 공통 "말씀 포인트" 적립 |
| 일일 미션 | 매일 각 게임별 도전 과제 제공 |
| 랭킹 | 게임별 + 통합 랭킹 (친구 초대 기반) |
| 업적 시스템 | 뱃지 & 칭호 (예: "방주의 건축자", "말씀 암송 챔피언") |
