# 갓모드 — 커뮤니티 기능 아이디어 (보류 풀)

> MVP에서 제외됐지만 방향성은 유효한 기능들. 추후 Phase 재검토용.

---

## 핵심 비전

*신뢰 기반의 기독교 생태계* — 아는 사람들끼리 연결, 교회 기반 커뮤니티

> "재미있고 가벼운 신앙인들끼리의 연결"

---

## 소셜 연결 구조

| 개념 | 설명 |
|------|------|
| 연결 기반 | 교회 / 셀 / 친구 |
| 연결 범위 | 아는 사람들끼리만 (오픈 커뮤니티 X) |
| 셀 이슈 | 셀은 바뀜 → 셀 기준 + 친한 사람 기준 병행 필요 |
| 단톡방 컨셉 | 최대 10명, 방장 구독으로 커버 |

---

## 커뮤니티 기능 목록

### 함께 묵상하기
- 성경 일독 동아리 형태
- 서로 응원/진도 확인
- 챌린지 구조

### 중보기도
- 기도 제목만 나누는 공간
- 소속 기반 (지역 X, 소속 O — 같은 교회/셀)
- 익명 옵션

### 친구 기록 열람
- 친구 맺기 → 상대방의 신앙 기록 열람
- To Do Mate 레퍼런스

### 활동 알림
- "현민님이 댓글을 달았어요"
- 서로간 활동 실시간 알림

### 커뮤니티 게시판
- 기독교 질문, 고민, 이슈 나눔
- 익명 가능

### 교회 CRM
- 교회별 공지사항 (인증 시에만 작성 가능)
- 목사님 어드민 — 교회 내부 정보 확인
- (구체적 정보 항목은 추후 정의 필요)

## 아이스브레이킹 게임팩

교회 소그룹에서 쓸 수 있는 이미지 게임 / 밸런스 게임

### "이 사람은?" 게임 (인물 지목 게임)

**외모/첫인상**
- 교회에서 가장 눈에 띄는 사람은?
- 가장 단정하게 차려입고 오는 사람은?
- 예배 때 가장 집중하는 표정이 인상적인 사람은?

**성격/관계**
- 처음 온 사람한테 가장 먼저 말 걸어줄 것 같은 사람은?
- 힘든 일 생겼을 때 제일 먼저 연락하고 싶은 사람은?
- 같이 있으면 시간이 빨리 가는 사람은?
- 가장 웃음이 많은 사람은?

**신앙/교회생활**
- 찬양할 때 가장 열정적인 사람은?
- 기도 부탁하면 진짜 기도해줄 것 같은 사람은?
- 말씀 묵상 제일 열심히 할 것 같은 사람은?
- 선교사가 될 것 같은 사람은?

**함께하고 싶은 것**
- 같이 봉사활동 가고 싶은 사람은?
- 교회 수련회 룸메이트 하고 싶은 사람은?
- 같이 성경공부 하면 재미있을 것 같은 사람은?
- 식사 나눔 때 꼭 옆에 앉고 싶은 사람은?

**유머**
- 교회 MT 가면 분위기 메이커가 될 사람은?
- 목사님 설교 중에 졸 것 같은 사람은?
- 헌금 봉투 제일 두툼하게 낼 것 같은 사람은?

## 데일리 콘텐츠 아이디어

- **성경 퀴즈:** 매일 퀴즈 → 점수 랭킹
- **위젯:** 오늘의 말씀, 친구 현황 (썸원 레퍼런스)
- **예배 말씀 띄우기:** 예배 때 해당 성경 말씀 즉시 표시
