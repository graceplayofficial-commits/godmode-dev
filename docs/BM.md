## 수익 구조 아이디어 (검토 중)

### 구독 모델

```
Free tier
├── 릴스 피드 (광고 포함)
├── 테스트 1회
└── 미니게임 일부

Premium (연 5만원)
├── 광고 없음
├── 테스트 무제한
├── 미니게임 전체
└── 친구 기록 열람 등 소셜 기능
```

### 단톡방 / 그룹 모델
- 방장이 구독하면 최대 10명 그룹 커버
- 교회 소그룹/셀 단위 구독 유도

### 후원 모델
- 앱 내 후원하기 버튼
- 크리에이터 후원 연동 가능성 검토
